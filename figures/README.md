# Figures

PNG outputs grouped by topic. Every figure here is used by the presentation deck (`docs/presentation/`); there is no surplus.

All deck figures are rendered in Times New Roman with all text ≥ 32 pt (titles 36–38 pt) for legibility in a 60-person room.

## Layout

```
figures/
├── eda/        # data overview, calibration, intraday seasonality, section roadmap
├── lagCorr/    # lead-lag cross-correlogram (slide 11)
├── varRatio/   # variance ratio diagnostic (slide 12)
└── logReg/     # incremental-information test + appendix LR diagnostics
```
