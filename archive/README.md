# Archive

This folder holds code and notes from earlier scope work that is **not** part of the current OQG presentation.

## Contents

- `polymarket/` — Polymarket data-collection scripts from an earlier exploration. The presentation analyzes Kalshi only; Polymarket scripts are kept here for reference in case the analysis is extended to a second prediction-market venue.

## Why this exists

The main `scripts/` tree is now organized around the three diagnostics actually shown in the deck (lead-lag, variance ratio, incremental information). Out-of-scope code lives here so the main tree reads cleanly to a reviewer.
